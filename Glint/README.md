# Glint

Détecteur de reflets pour iPhone. La caméra entoure en direct les points qui
brillent plus que leur entourage — pratique pour retrouver un petit objet
réfléchissant tombé par terre (boucle d'oreille, bijou, vis, lentille…).

- Le plus brillant est entouré en jaune, les autres en blanc.
- La lampe (allumée par défaut) fait scintiller les objets réfléchissants.
- Le curseur règle la sensibilité.

iOS 16 minimum. IPA non signée produite par GitHub Actions (release `glint-v*`).
À installer avec SideStore, AltStore ou Sideloadly.
